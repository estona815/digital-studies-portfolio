체험 화면으로 돌아가기

스와이프로 만나고,
매칭에서 우리로.

발견

손가락으로 왼쪽 넘기기·오른쪽 좋아요, 버튼과 키보드 조작, 마지막 넘김 되돌리기, 취향 검색, 프로필 상세, 신고·차단. 성인 가상 계정의 첫 화면에는 여덟 명의 성인 후보가 있습니다. 청소년 계정은 가까운 연령대 친구만 보여줍니다.

우리

상호 좋아요 → 매칭 → 두 사람의 커플 확인 → 별도 위치 공유 동의. 예시 위치·거리·갱신 시각·즉시 공유 종료, 오늘 기분, 데이트 약속 제안과 수락, 기념일 제안과 확인, 함께 하고 싶은 일 목록, 개인 일기를 체험합니다.

대화와 모임

친구 요청·수락·대화, 성인 매칭 대화, 모임 생성·참여·게시판, 모임 장소·시간 투표를 유지합니다. 사진 등록·운영자 승인, 내 데이터 내려받기, 계정 삭제 체험은 오른쪽 위 내 정보에서 확인합니다.

한 번에 확인하는 순서

나루 계정에서 첫 유나 카드를 오른쪽으로 넘기면, 미리 준비된 상대 좋아요로 매칭됩니다. 우리 공간에서 유나에게 커플 확인을 요청하고 상대 가상 화면으로 바꿔 수락합니다. 그다음 위치 공유를 요청하고 다시 상대 계정으로 바꿔 별도로 동의해 보세요. 실제 상대방에게 알림을 보내는 기능이 아닙니다.

검수 범위

새 상태 모델 53개 검사, 실제 DOM 화면 시나리오 31개, Chromium 모바일 터치·필터·키보드 시나리오 5개를 통과했습니다. 터치 캡처가 자식 요소에서 카드로 옮겨갈 때 드래그가 취소되던 문제를 수정했습니다.

Browser 전용 플러그인이 없어 Playwright/Chromium을 사용했습니다. 환경에서 로컬 주소 직접 탐색이 차단되어, 동일 JavaScript와 CSS를 해시로 허용한 DOM 문서로 실행했습니다. 사진의 로컬 검수본은 같은 원본을 재인코딩해 사용했습니다. 실제 라이브 전송 계층·물리 iPhone Safari·GPS·실회원 서버 검증 결과가 아닙니다.

아직 연결하지 않은 것

실제 회원, 본인·연령 인증, 실시간 GPS, 휴대폰 푸시, 유해 이미지 자동 심사, 실제 데이터베이스, 광고와 결제는 연결하지 않았습니다. 모든 계정과 위치는 가상이며 새로고침하면 초기화됩니다. 이 검수본 배포는 실회원 운영 승인이나 무결함 보증이 아닙니다.
