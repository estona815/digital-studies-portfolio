지금 가능한 기능

무료 체험판은 온라인에 올릴 정적 파일만 포함합니다. 소스 검수와 운영 서비스 개통을 구분합니다.

기능이 체험판의 상태
카드·취향·필터가상 사용자로 체험
성인 매칭·메시지가상 계정 간 메모리 시뮬레이션
모임·장소·시간가상의 장소 후보와 투표
프로필·사진·다운로드이 탭에서만 처리
운영 검수·삭제샘플 상태 변경
실회원 가입·실제 연락제공하지 않음
광고·결제·위치추적제공하지 않음

안전하게 체험하기

성인·청소년 선택은 가상 테스트 계정을 바꾸는 동작일 뿐 나이 인증이 아닙니다. 만 14세 미만 서비스는 지원하지 않고, 성인 연애 기능과 청소년 친구·모임 기능을 분리하는 설계를 유지합니다.

무료 범위

이 파일은 외부 유료 API·서버·데이터베이스를 호출하지 않습니다. 웹페이지 배포와 방문에는 호스팅 무료 플랜의 사용량 한도가 적용됩니다. 무료 플랜의 한도를 초과하면 페이지가 중지될 수 있습니다. 무제한 접속이나 광고 수익을 보장하지 않습니다.

운영 서비스 출시 전

원래 호스트 전체 통합, PostgreSQL 동시성·백업·복구, 실제 인증·저장소·신고 대응·개인정보 고지·광고 승인 검증이 필요합니다. 이 체험판을 업로드해도 실회원 서비스로 바뀌지는 않습니다.
