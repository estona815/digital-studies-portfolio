상호 좋아요 → 커플 요청 → 상대 계정에서 확인. 위치 공유는 별도 요청과 동의 후 1시간만 제공하는 가상 기능입니다. 새 요청에는 새 동의가 필요합니다. 예시 위치는 5분 이상 갱신되지 않으면 지도에서 숨기고, 중단·차단·연결 종료 시 위치와 관련 알림을 제거합니다.

데이트 장소·시간 제안과 수락, 서로 확인하는 기념일, 함께 하고 싶은 일, 자정에 지워지는 선택형 기분 공유, 가상 계정별 일기·작성 중 초안을 체험합니다.

이번에 확인한 범위

로직 검사 42개와 브라우저 화면 시나리오 49개를 통과했습니다. Chromium의 360·390·430·768·1024·1440px 화면, 터치·키보드 스와이프, 계정 전환과 동의 철회 등을 확인했습니다. 이는 검수본 코드 검사이지 보안 인증이나 무결함 보장이 아닙니다.

브라우저의 직접 사이트 이동이 실행 환경에서 차단되어, 동일한 스크립트와 CSS를 DOM에 넣어 검사했습니다. 사진은 로컬 검사용으로 같은 원본 이미지를 넣었습니다. 실제 호스팅 전송 계층과 실제 아이폰 Safari 검사는 별도입니다.

아직 연결하지 않은 것

실회원 가입·연령 인증 업체·회원 데이터베이스·타인과의 실제 메시지·GPS·백그라운드 추적·휴대폰 푸시·광고·결제는 모두 OFF입니다. 이 링크에서 실회원 정보를 모집하거나 수익형 서비스를 운영하지 않습니다. 화면이 작동한다고 실회원 운영 준비가 완료된 것은 아닙니다.

청소년 가상 계정에는 또래 친구·모임 기능만 표시하고, 커플·위치 공유는 성인 가상 계정끼리만 제공합니다. 14세 미만 가입은 지원하지 않습니다. 이 경계는 검수본 설계이며 일반적인 법률 판단이 아닙니다.

원래 앱의 PostgreSQL·인증·저장소·신고 대응·개인정보 처리·광고 승인을 실제 환경에서 검증한 후 별도로 출시해야 합니다. 기존 서비스의 운영 설정을 우회하지 않습니다.

다른 서비스와 무관한 독립 인터페이스 검수본입니다. 가입·구독·카드 등록 없이 화면을 확인할 수 있으며, 모든 입력은 이 탭 안에만 남고 새로고침하면 사라집니다.
