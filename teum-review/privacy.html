무료 체험판 개인정보 안내

이 사이트는 가상 계정을 사용하는 화면 체험판입니다. 실회원 가입과 다른 이용자와의 연락 기능은 열려 있지 않습니다.

직접 입력한 내용과 사진

프로필 수정, 대화 입력, 사진 선택 등은 열린 탭의 메모리 안에서만 처리됩니다. 애플리케이션은 이를 서버로 업로드하거나 다른 사람에게 보내지 않습니다. 실제 얼굴 사진, 연락처, 학교, 집 주소 등은 입력하지 마세요.

새로고침하면 샘플 상태로 돌아갑니다. 별도로 다운로드한 JSON 파일이나 화면 캡처는 사용자의 기기에 남을 수 있으므로 직접 삭제해야 합니다. 브라우저 자동완성·뒤로 가기 캐시 등 브라우저 자체 기능의 기록 삭제를 보장하지는 않습니다.

접속 기록

웹페이지를 전달하는 호스팅 업체는 IP 주소, 요청 URL, 접속 시각 같은 기본 요청 정보를 처리할 수 있습니다. 앱에 실회원 데이터베이스는 없으며 광고·외부 분석 스크립트·위치추적 기능을 넣지 않았습니다.

체험용 삭제·운영자 기능

계정 삭제 접수·운영자 승인 버튼은 이 탭의 샘플 상태만 변경합니다. 실제 외부 계정 삭제, 유해 이미지 심사 또는 신고 접수 완료를 뜻하지 않습니다.

실서비스 전환

연령 인증, 운영 책임자, 개인정보 처리·보존·신고 대응 방침, 실제 제공자 계약을 확인하기 전에는 실회원 모집을 하지 않습니다. 이 안내는 체험판에 대한 설명이며 실제 서비스 약관이나 법률 검토를 대체하지 않습니다.
