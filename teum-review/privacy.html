개인정보 안내

가상 계정으로 기능을 확인하는 무료 검수본입니다. 실제 회원 가입, 다른 사람과의 연락, 광고와 결제는 연결하지 않았습니다.

사람과 매칭

이름·나이·소개·취향은 모두 만들어 둔 가상 데이터입니다. 일부 상대 좋아요와 기존 매칭은 체험을 위해 미리 준비되어 있습니다. 실제 이용자 수, 실제 접속 상태, 본인·연령 인증 결과가 아닙니다. 청소년 가상 계정에는 가까운 연령대의 친구 기능을 제공하고 성인 커플 기능을 열지 않습니다.

입력한 글과 사진

프로필, 대화, 사진, 일기, 약속, 기념일, 함께 할 일은 열린 탭의 메모리에서 처리됩니다. 앱은 이를 서버에 업로드하거나 다른 사람에게 보내지 않습니다. 실제 얼굴 사진, 학교, 집 주소, 연락처, 민감한 사생활은 입력하지 마세요.

일기는 가상 계정별로 구분한 샘플이며 실제 인증이나 암호화 보관 서비스가 아닙니다. 새로고침하면 샘플 상태로 돌아갑니다. 다운로드한 JSON과 화면 캡처는 기기에 남을 수 있습니다. 브라우저 자동완성·뒤로 가기 캐시·외부 저장본 삭제는 보장하지 않습니다.

위치 공유 체험

매칭만으로 위치를 표시하지 않습니다. 두 성인 가상 계정이 커플 연결을 확인한 뒤, 별도의 위치 공유 요청과 상대의 동의를 거쳐 1시간 동안만 체험합니다. 요청은 10분 후 만료됩니다.

지도 모양 화면의 위치와 거리도 예시입니다. 각 계정은 준비된 가상 장소 버튼으로 자기 예시 위치만 바꿉니다. GPS·실제 좌표·동선·민감한 방문 장소를 수집하지 않으며 브라우저 위치 권한과 푸시 권한을 요청하지 않습니다. 실제 백그라운드 위치 추적과 휴대폰 알림을 제공하지 않습니다.

한 계정당 마지막 예시 위치만 보관하고 이동 경로를 쌓지 않습니다. 양쪽 중 누구든 끌 수 있습니다. 차단·연결 해제·삭제·만료를 확인하면 공유 위치를 닫습니다. 브라우저가 멈춘 동안에는 다음 화면 처리 시 만료를 확인합니다.

기분과 함께 쓰는 기록

기분은 직접 선택했을 때만 상대 가상 계정에 표시하고 다음 한국 날짜가 되면 지웁니다. 정신건강 상태를 추정해 추천하거나 광고 대상으로 사용하지 않습니다. 기념일과 데이트 약속은 상대 확인을 받아 표시합니다. 커플 연결을 종료하면 공유 위치와 함께 쓰던 약속·기분·기념일·할 일을 제거합니다.

접속 로그와 운영 체험

호스팅 업체는 페이지 전달에 필요한 IP 주소, 요청 URL, 접속 시각 같은 기본 접속 정보를 처리할 수 있습니다. 앱에 광고·외부 분석 스크립트와 실회원 데이터베이스는 없습니다.

신고, 사진 승인, 계정 삭제 버튼은 현재 탭의 샘플 상태만 변경합니다. 실제 신고 접수·유해 이미지 심사·외부 계정 삭제 완료를 뜻하지 않습니다. 제공자 인증, 실제 서버, 운영 책임자와 개인정보 방침 검증은 별도 과제입니다. 이 안내는 실제 서비스 약관이나 법률 검토를 대체하지 않습니다.
